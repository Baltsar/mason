Apprentice source on GitHub

It watches you work. Then it asks why.

Apprentice sits behind real work on a Mac. It stays quiet while you type, asks one spoken question at the pause, and turns your answers into a Work Map and a tutor that stops the next person before they break your rule.

04 Run it

It lives on your Mac, not here.

git clone __REPO__
cd apprentice
cp .env.local.example .env.local   # add an ElevenLabs key
open "Start Apprentice.command"

Events, not pixelsNo screenshots and no keystroke log. It reads the front app, the window title and the prompt field.

Private by defaultPassword managers, mail, chat and banking are refused before anything is written. One press pauses everything.

ElevenLabsAgents for the debrief and the tutor, Flash v2.5 for speech, Scribe v2 Realtime for answers.

One memory, every agentThe Work Map is also an MCP server, so other agents can check a decision before they act.
